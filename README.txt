Connect Four Gauntlet - installable PWA

Host these files on any HTTPS static host (GitHub Pages, Netlify, Vercel,
Cloudflare Pages). Open the URL on your phone and choose "Add to Home Screen"
(iPhone: Share > Add to Home Screen; Android/Chrome: Install app).

After the first visit it works offline with the built-in engine.
On "Impossible" + "Solver + engine" it also asks the free online perfect
solver at connect4.gamesolver.org each move, and falls back to the
built-in engine if that site is unreachable.
